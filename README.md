# TTN Fire Safety Solution — website

Website tĩnh của Công ty TNHH PCCC & An Toàn TTN, chạy bằng nginx trên Vibe Host.

- `site/`: nội dung website (bản sao của `website/public`, không sửa trực tiếp ở đây).
- `Dockerfile`, `nginx.conf`: cấu hình chạy.

Cập nhật: sửa trong thư mục `website`, chạy `website/day-len.ps1` để đồng bộ, commit và đẩy lên; sau đó triển khai lại trên Vibe Host.
